# Сравнение с `mvn dependency:tree`

Штатный инструмент визуализации Maven - плагин `dependency:tree`.
Сравнение выполняется для трёх пакетов с Maven Central (нужны Maven и
интернет). Для каждого пакета:

1. В `docs/compare/pom.xml` подставьте координаты пакета.
2. Штатный вывод: `mvn -f docs/compare/pom.xml dependency:tree`
   (с дублями и конфликтами: добавьте `-Dverbose`).
3. Наш вывод: `./run.sh tests/data/configs/central_jackson.csv`
   (ASCII-дерево и файлы `out/*.puml`, `out/*.png`).
4. Занесите результат в таблицу ниже.

| Пакет | Вершин в mvn | Вершин у нас | Расхождения |
|---|---|---|---|
| com.google.guava:guava:31.1-jre | заполнить | заполнить | заполнить |
| com.fasterxml.jackson.core:jackson-databind:2.15.2 | заполнить | заполнить | заполнить |
| org.apache.commons:commons-text:1.10.0 | заполнить | заполнить | заполнить |

## Почему результаты могут различаться

1. **Разрешение конфликтов версий.** Maven оставляет одну версию
   артефакта ("ближайшая побеждает"). Наш граф хранит каждую пару
   `группа:артефакт:версия` отдельной вершиной, поэтому один артефакт
   может встретиться в нескольких версиях.
2. **Дубликаты.** Maven показывает артефакт в дереве один раз (в
   режиме `-Dverbose` - с пометкой об исключении дубля). Мы строим граф:
   общая зависимость - одна вершина с несколькими входящими рёбрами, а в
   ASCII-дереве повторы помечены `(повтор)`.
3. **Области видимости (scope).** Для корневого проекта mvn показывает
   также `test` и `provided`. Мы учитываем только `compile` и `runtime`
   на всех уровнях, `optional` пропускаем.
4. **Исключения (`<exclusions>`)** Maven применяет, мы - нет, поэтому у
   нас могут быть лишние ветки.
5. **BOM и `scope import` в `dependencyManagement`.** Мы их не
   разворачиваем: зависимости без версии пропускаются с предупреждением,
   у Maven версия будет определена.
6. **Диапазоны версий, relocation, SNAPSHOT-метаданные.** Для диапазона
   берётся нижняя граница, остальное не обрабатывается.
7. **Профили и условные зависимости** (`<profiles>`, `activation`) мы
   не учитываем.
8. **Тип и classifier артефакта** (`jar`, `pom`, `tests`) игнорируются,
   различие по ним не отражается.
9. **Циклы.** Maven не допускает циклов; в нашем инструменте они
   возможны (например, в тестовом репозитории) и выводятся явно.
