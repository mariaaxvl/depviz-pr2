# Визуализатор графа зависимостей (Maven)

## 1. Общее описание
CLI-инструмент на Python 3 для анализа и визуализации графа
зависимостей Maven-пакетов. Готовые менеджеры пакетов и библиотеки для
получения зависимостей не используются. Реализованы этапы 1-4: конфигурация CSV, чтение зависимостей Maven по
URL, построение графа (DFS), тестовый режим, обратные зависимости.

## 2. Функции и настройки
Запуск: `./run.sh config.csv`. Конфигурация - CSV из строк
`ключ,значение` (первая строка `key,value` необязательна):

| Ключ | Значение |
|---|---|
| `package` | `группа:артефакт:версия` (в тестовом режиме - `A`, `B`...) |
| `repo` | URL репозитория или путь к файлу тестового репозитория |
| `test_mode` | `true` - тестовый репозиторий, `false` - Maven по URL |
| `output` | имя файла изображения, `*.png` |
| `ascii_tree` | `true` - вывести ASCII-дерево |
| `filter` | подстрока: пакеты с ней в имени не анализируются |
| `reverse` | необязательный; `true` - вывести обратные зависимости |
| `universe` | необязательный; Maven-пакеты через `;` для `reverse` |

Код возврата: 0 - успех, 2 - ошибка конфигурации, 3 - ошибка
репозитория, 4 - ошибка графа. Сообщения об ошибках выводятся в stderr.

Прямые зависимости берутся из POM (`parent`, `${свойства}`,
`dependencyManagement`); учитываются scope compile и runtime,
`optional` пропускаются.

Граф строится рекурсивным DFS с учётом транзитивности. Циклы
находятся и выводятся, обход всегда завершается. Пакеты, в имени
которых есть подстрока `filter`, не анализируются.

Тестовый режим (`test_mode,true`): `repo` - путь к файлу, где каждая
строка `ПАКЕТ: ЗАВИСИМОСТИ` (имена - заглавные латинские буквы,
`#` - комментарий), например `A: B C`.

Режим `reverse,true`: показываются пакеты, которые зависят от
`package` (прямо и транзитивно). Строится полный граф тем же DFS,
рёбра обращаются, затем DFS идёт по обращённым рёбрам. В тестовом
режиме берутся все пакеты файла; у Maven нет индекса обратных
зависимостей, поэтому корни набора задаёт `universe`, например
`com.example:root:1.0;com.example:app:1.0`.

## 3. Сборка и тесты
    PYTHONPATH=src python3 -m unittest discover -s tests
    ./tests/stage1.sh
    ./tests/stage2.sh
    ./tests/stage3.sh
    ./tests/stage4.sh
    CENTRAL=1 ./tests/stage2.sh   # реальный Maven Central, нужен интернет

## 4. Примеры
    $ ./run.sh tests/data/configs/test_simple.csv
    Граф зависимостей пакета A: вершин 4, рёбер 4
      A -> B, C
      B -> D
      C -> D
      D -> (нет зависимостей)
    Циклических зависимостей не найдено.

Обратные зависимости (`reverse,true`, пакет `D`):

    Обратные зависимости пакета D (пакеты, зависящие от него): 3
      D <- B, C
      B <- A
      A <- (никто не зависит)
      C <- A
    Циклических зависимостей не найдено.
